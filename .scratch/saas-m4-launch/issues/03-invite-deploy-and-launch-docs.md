## Comments

### 实现说明（票 03）

- OAuth 回调在 `invite` 模式下继续放行已注册用户和管理者。两种数据库都复现了已经配置管理者时，空库仍允许陌生人抢先注册的问题。现在仅在名单和用户表都为空时允许第一位用户直接注册，以便查出自己的登录标识。部署说明要求在对外开放前配置名单。`eidolon doctor` 的终端输出及 JSON 均提示缺少管理者。
- 现有 `/api/admin/invites` 列表、创建和删除接口在 SQLite、PostgreSQL 上都实测。OAuth 仅替代外部提供方。普通用户同意条款后，三个后台操作均返回 404。规范审阅指出这一步原先未覆盖，现已补上。
- 两套生产 Compose 对前端、后端和通话服务使用本地构建。用 `.env.example` 和合成值解析确认单进程与 PostgreSQL 拆分配置、公开源码构建参数和邀请设置。环境示例取消了空的 SQLite 路径赋值，以便使用实际默认文件。
- 需求审阅发现测试仍有原作台词和角色设定。已删除未被调用的旧 CSV 资料样例，给仍在使用的剧情、角色和配色测试换上原创样例。删除含原作角色的开发截图、重置卡图和引用原作的旧实验回复，保留实验统计。部署文档中移除了上游镜像说明。模型、语音等凭据在环境示例中留空；`LICENSE`、`LICENSING.md` 与上游起点逐字节相同。
- 邀请与 doctor 测试 21 项通过，Ruff、Pyright 通过。前端 787 项、类型检查、纪律脚本和生产构建通过。`sh scripts/affected-tests.sh 49949ab8` 的后端 363 项、前端 615 项通过。构建仍有 `LINE Seed JP` 字体提示，后端有现有弃用提示。Compose 只解析配置，临时文件、测试数据库和进程均已清理。
