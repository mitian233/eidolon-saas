# M4 公益上线

本阶段的第一张票落实[改造设计](../../docs/ryugi/specs/2026-11-12-saas-byok-design.md)第 2、3、5 节的站点说明和通知-删除流程。

- 使用条款和隐私政策说明私有角色、导入资料、头像外链、用户自带密钥和第三方处理。页脚提供举报和 AGPL 对应源码入口。
- 访客和登录用户都能提交举报。后台按状态查看并记录处理结果，通过现有用户管理执行封禁、解封或删除。
- 举报是独立的处置记录。公开表单只请求定位和处理所需的信息，联系方式可留空。后台把举报中的链接按文本展示。

## Testing Decisions

用 HTTP 接口和真实 SQLite、PostgreSQL 测试举报、限频、管理员访问和账户清除。通话结束用现有测试浏览器观察。条款和举报页面用 Playwright 在本地构建版中走完整流程。
